# New Jersey — An Atlas of Names

Explore the name journeys of New Jersey municipalities in two editions:

- [The Atlas](https://sanchezbrent.github.io/nj-name-atlas/primary/)
- [Young Explorers](https://sanchezbrent.github.io/nj-name-atlas/young-explorers/)

[Choose an edition](https://sanchezbrent.github.io/nj-name-atlas/).

## Research scope

This is a research pilot. Twelve profiles reflect the current review; 552 retain earlier research records. The atlas preserves source notes, uncertain dates and open questions. Publication does not mean every profile has received the current review.

## Young Explorers notes

Notes are saved in your browser only when you choose Save. Download a copy to keep it. Notes saved at another address do not move here automatically. There is no account sync or note transmission service.

## Hosting

The self-contained static website lives in `docs/`. GitHub Pages uses the `main` branch and `/docs` folder. No build dependencies or custom domain are required. No workbook, audit file or raw export is included.

The original pilot documents are preserved separately. These publishing copies change only the visible “Private pilot” label to “Research pilot”; their atlas scripts, embedded data, fonts and original controls are unchanged.
