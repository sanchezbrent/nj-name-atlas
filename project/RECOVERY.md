# Recover and continue

Clone this public repository for the exact website source and run the checks in
[CONTRIBUTING.md](../CONTRIBUTING.md). Pages uses `main` and `/docs`; the public
website has no build dependencies. Restore a previous reviewed asset set through
a new PR, preserving history. Never force-reset the remote to perform a rollback.

The complete historical project belongs in the private companion repository,
`sanchezbrent/nj-name-atlas-research`. C15 inventories existing workspace files by
SHA256, maps duplicate files to sealed nested checkpoints, and packages any extra
files separately. Caches, downloaded tool runtimes and credential-like paths are
recorded exclusions. Originals and native workbook features are preserved.

Large archive uploads are currently deferred by the user. Until the private
release's assets, checksums and restore receipts are verified, retain the local
authority packets. Do not describe the remote archive as complete.

After the archive transfer is resumed, follow its private recovery index and
verify all asset SHA256 values before restoring. Restore into a new directory;
never overwrite the only authority copy. Reinstall excluded runtimes/dependencies
from locked instructions. Read the latest checkpoint and protected-field rules
before editing history. Local notes are not part of this project archive.
