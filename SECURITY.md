# Security and private project material

Never post credentials, browser notes, private workbooks, raw exports, audit files
or internal checkpoint packets in this public repository, issues or pull requests.
Keep those materials in the private research companion and controlled local copies.

For a sensitive finding, use an established private channel with the repository
owner, or GitHub private vulnerability reporting if enabled. A public bug report
should contain only a non-sensitive description and reproduction steps.

The atlas is a public static research pilot. Noindex and robots directives do not
provide authentication. Notes use the visitor's browser storage when explicitly
saved; hosting at another address does not migrate previous notes.

CI has read-only repository permission, no deployment credential and a verified
full-SHA checkout reference. Do not add `pull_request_target` execution of proposed
code, print credentials or grant broad write permission to routine checks.
